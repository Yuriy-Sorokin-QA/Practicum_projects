"Яндекс.Самокат" Это сервис, который позволяет арендовать электрический самокат на несколько дней.
Первое задание — тестирование веб-приложения(чек-листы, данные валидации, исследовательское тестирование).
Второе задание — тестирование мобильного приложения(тест-кейсы).
Третье задание — тестирование API(чек-листы).
Отчёт:
При проведении тестирования было выявлено большое количество багов, выпуск приложения необходимо отложить до исправления блокирующих и критических багов.
